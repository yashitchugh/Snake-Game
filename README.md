# 🐍 Snake Game – HTML/CSS/JavaScript 🎮

This is a classic **Snake Game** made with **HTML, CSS, and JavaScript**. The game features images for the background, snake, and food, which are downloaded from the browser and included in the project.

---

## 🎯 Features

- Smooth and responsive gameplay
- Uses arrow keys for control
- Image-based background and food items
- Basic score tracking
